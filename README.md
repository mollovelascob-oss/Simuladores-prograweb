## 🚀 Descripción del Proyecto
La plataforma web centraliza dos simuladores lógicos y matemáticos:
1. **Simulador de Transferencia de Calor:** Aplica la Ley de Enfriamiento de Newton para calcular variaciones de temperatura.
2. **Calculador de Combinaciones:** Resuelve la lógica de combinaciones por grupos para sorteos simultáneos.

## 📁 Estructura del Repositorio
El código está organizado de manera limpia separando las responsabilidades de diseño y lógica:
* `index.html` - Estructura semántica de la página y formularios.
* `CSS/style.css` - Diseño visual, tipografía y estilos de la interfaz.
* `JS/script.js` - Funciones lógicas en JavaScript y procesamiento de los simuladores.
